# knowledge

Public demo corpus for the proof registry. Statements are synthetic.
Replace this directory with your own profile, career notes, and projects
when you run the system for yourself. Do not put secrets in these files.

| Path | Role |
| --- | --- |
| `profile.md` | Demo identity facts the registry may cite |
| `career/` | Demo career facts |
| `projects/` | Demo project facts |
| `proof-registry.yaml` | One claim, one verification status, one source |
| `positioning.md` | Demo stance. Not evidence |
| `content-strategy.md` | Lanes and audience. Not evidence |
| `voice.md` | Drafting preferences. Not evidence |
| `guardrails.md` | Hard limits |
